# Tarea A — Brief de lanzamiento: seis fuentes independientes

## Contexto

Horizonte, una empresa ficticia de software de facturación, considera lanzar el módulo **Cobranza Pro** el 15 de octubre. Tienes seis notas internas independientes en `fuentes/tarea-a/`.

## Tu trabajo

Lee las seis fuentes y entrega un brief de decisión de máximo 450 palabras con este formato exacto:

```text
DECISIÓN: LANZAR / LANZAR CON CONDICIONES / POSPONER

EVIDENCIA POR FUENTE
- A1: …
- A2: …
- A3: …
- A4: …
- A5: …
- A6: …

TRES RIESGOS PRIORIZADOS
1. [riesgo] — [por qué] — [mitigación] — [fuente]
2. [riesgo] — [por qué] — [mitigación] — [fuente]
3. [riesgo] — [por qué] — [mitigación] — [fuente]

CONDICIONES PARA LANZAR
- …
```

## Restricciones

- Usa solamente las fuentes A1–A6 del repositorio.
- No inventes datos ni sustituyas identificadores de fuente.
- Si dos fuentes se contradicen, nombra ambas y convierte la contradicción en condición o riesgo.
