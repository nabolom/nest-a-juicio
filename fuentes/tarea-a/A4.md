# A4 — Finanzas (corpus sintético)

El lanzamiento tiene presupuesto para una semana de soporte extraordinario. Si se extiende a dos semanas, el margen del trimestre cae de 24% a **20%**. Finanzas aprueba el lanzamiento si se mantiene el alcance actual y no se ofrece una garantía de ahorro a los clientes.
